# データのライセンスと商用利用（2026-10-04 調べ）

店舗物件の仲介会社向けの有料サービスにする前提で、使っている／使う予定のデータの利用条件を確認した。
この作業環境からは公式ページの多く（docs.overturemaps.org、nlftp.mlit.go.jp、geospatial.jp）を直接開けないため、
**検索結果に出た公式ページの記載で確認した**。有料化の前に、★の付いた項目は公式ページを人の目で確認すること。

## 結論

| データ | 使っている所 | 条件 | 有料サービスで |
|---|---|---|---|
| Overture Places（店舗） | 店の件数・ジャンル | CDLA-Permissive-2.0。一部（Foursquare 由来）は Apache-2.0、一部 CC0 | **使える**。出典表示が必要。Foursquare 由来分は Apache-2.0 の写しと NOTICE（"Copyright 2024 Foursquare Labs, Inc. All rights reserved" など）を残す。OSM 由来のデータは含まない |
| Overture Transportation（線路） | 地図の路線 | ODbL（OpenStreetMap 由来） | 地図として見せるだけなら出典表示（© OpenStreetMap contributors）で可。線路データ自体を配る・他のデータと組み合わせたデータベースとして配ると、ODbL の継承条件がかかる → **国土数値情報 N02（鉄道）に置き換える** |
| Overture Divisions（区の境界） | 店の区の割り当て、地図の区の線 | ODbL | 同上。店データに区を付ける処理にも使っているので、**国土数値情報 N03（行政区域）に置き換える** |
| 国土数値情報 S12（駅別乗降客数）S12-25 | 乗降客数、駅の位置 | **公共データ利用規約（第1.0版）**（ユーザーがデータページで確認、2026-10-04。https://www.digital.go.jp/resources/open_data/public_data_license_v1.0） | **使える**。出典表示と、加工したことの表示が必要。CC BY 4.0 互換。検索で出る古い版（v2.x など）のページは「非商用」なので、**使う版は S12-25 以降に限る**。データページに第三者の権利などの個別の除外が書かれていないか確認する ★ |
| 東京都統計年鑑「運輸」（JR の駅別乗車人員、私鉄の駅別乗降車人員、地下鉄の乗降人員、日暮里・舎人ライナー） | 使わない（都内だけのデータで、他の地域に広げられないため。ユーザー方針 2026-10-04） | CC BY 4.0（東京都オープンデータカタログ） | **使える**。出典表示が必要。JR は「乗車人員」なので、乗降客数とは定義が違う（おおむね2倍にすると乗降に近い）。定義の違いを画面に書く |
| 国土数値情報 N02（鉄道）・N03（行政区域） | （置き換え先） | 公共データ利用規約（第1.0版）（ユーザーがデータページで確認、2026-10-04） | **使える**。出典表示と加工したことの表示が必要 |
| 経済センサス2021、国勢調査2020（e-Stat） | センサス補正、（予定）人口・年齢・働く人の数 | 政府標準利用規約 2.0（CC BY 4.0 互換） | **使える**。出典表示が必要。加工したときは加工したことを書く |
| 全国の人流オープンデータ（国土交通省、1km メッシュ） | （予定）昼間の滞在人口 | 商用利用可（専用の利用規約）★ | 使える見込み。利用規約 PDF を確認する |
| 国土数値情報 L01（地価公示） | （予定）駅周辺の地価 | 平成31年以降はオープンデータ（CC BY 4.0／公共データ利用規約）★ | 使える見込み。出典「国土数値情報（地価公示データ）」（国土交通省） |
| 駐車料金（PPPark!、NAVITIME、Parkopedia など） | （検討）地価の代わり | 有料の法人向けデータのみ | 無料で商用に使えるものはない。`docs/parking_research.md` |
| 民間の推計所得（ゼンリン、技研商事、ESRI ジャパンなど） | （予定）所得 | 契約による | サービス上の表示・再配布ができるか、契約ごとに確認 |
| Claude（Anthropic API）による店名のジャンル判定 | ジャンル判定の一部 | Anthropic の利用規約（API の商用規約では、出力の権利は利用者側） ★ | 使える見込み。個人のアカウントで実行したので、事業で使うなら事業用アカウントの規約で確認する |
| 亀戸だけで使った OpenPOI（JFF）、OpenStreetMap（Overpass） | 亀戸の試行のみ | ODbL など | 23区の集計・サービスには使っていない。使う場合は別途確認 |

## サービスで必要な出典表示（案）

- 店舗データ: © Overture Maps Foundation（Places, CDLA-Permissive-2.0）。一部 © Foursquare Labs, Inc.（Apache-2.0）
- 乗降客数: 東京都「東京都統計年鑑」（CC BY 4.0）を加工して作成
- 人口・事業所: 総務省統計局「国勢調査」「経済センサス‐活動調査」（e-Stat）を加工して作成
- 鉄道・行政区域: 国土交通省「国土数値情報（鉄道データ・行政区域データ）」を加工して作成

## 店名の一覧（競合店リスト）を見せる・配ることについて

Places は CDLA-Permissive-2.0 / Apache-2.0 で、店名や位置を含めて再配布は可能。条件は出典表示と、Apache-2.0 分の NOTICE の保持。
ただし実在の店名を並べるので、閉店済みの店が残っている可能性（confidence の低い店は除いている）を画面に明記する。
