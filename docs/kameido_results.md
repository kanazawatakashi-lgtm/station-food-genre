# 亀戸駅 1km 圏の飲食ジャンル（試作・第1版）

2026-10-02 作成。**Overture＋JFF（食品営業許可、OpenPOI 経由）＋OSM のタグ**。
数字の元は `data/kameido/genre_table.csv`、店ごとの判定は `data/kameido/genre.csv`。

## 対象と判定率

- Overture 937 件 → 飲食店でないもの 27 件を除外 → 910 件
- JFF（OpenPOI 経由の食品営業許可・届出）313 件を突き合わせ（`scripts/merge_jff.py`、下記）→ **Overture に無い飲食店 95 件を追加**
- 合計 1,005 件 → 同一店の重複9組をまとめて **対象 996 件**
- 判定の内訳（重複をまとめる前の1,005件）: 店名ルール 532 / Overture 細分類 258 / JFF の店名 2 / OSM のタグ 5 /
  Claude の店名判定 71 / **判定不能 137**
- **最終判定率 86.2%**。比較用のルールのみの判定率は 81.8%（23区は 73.4%）

## 特化係数（LQ）の読み方

- 比較対象は **東京23区をおおむね覆う bbox 内の Overture 飲食 POI**（138,909 件、飲食店以外を除き重複をまとめて 135,837 件）。23区の境界では切っていないので、
  隣接する市の一部も入っている
- 駅側も23区側も「Overture の店」を「店名ルール＋Overture」だけで判定した結果で比べている
  （JFF の追加分と Claude 判定は23区側に無いため、LQ には入れていない。件数・構成比の列には入っている）
- 構成比の分母は判定できた店だけ
- 重複レコードは両側とも同じ条件（50m 以内・店名の中核が一致または包含・同じジャンル）でまとめてから数えている
- **件数が10件未満のジャンルの LQ は参考程度**。1〜2店の増減や重複レコードで大きく動く

## 読み取れそうなこと（暫定）

件数が多く、分類の揺れにも強いものだけ挙げる。

- **多い（LQ 1.3以上・20件以上）**: 焼肉・ホルモン 1.45、ラーメン 1.48、焼き鳥・やきとん 1.39。
  肉・麺・串の店が厚い
- **少ない（LQ 0.8未満）**: カフェ・喫茶 0.50（57件）、すし 0.72（26件）、パン 0.67（17件）、
  そば・うどん 0.61（12件）、フレンチ・ビストロ 0.61（11件）。後ろの3つは件数が少なめなので幅を持って読む
- 酒場系（居酒屋＋バー＋スナック・パブ）をまとめると LQ **1.04** でほぼ平均並み。居酒屋 1.59 とバー 0.79 の差は、
  店名に「居酒屋」「酒場」と書く店が多いかどうかと、Overture が izakaya を bar と sake_bar のどちらに入れるかの
  違いでほぼ説明できる。酒場系の中の内訳は今のところ比べられない

## 誤差の主な原因

1. **重複レコード**: 同じ店が複数レコードになっている。保守的な条件（`scripts/dedupe.py`）で9組はまとめたが、
   表記違い（Lali Guras／ラリグラス）、距離が離れたもの（亀戸升本）、ジャンルが割れたもの（ざうお）は残っている。
   23区側の重複除去は 1.3%。JFF との名寄せのときに条件を見直す
2. **カフェの比較対象**: Overture の cafe / coffee_shop には飲食店でないもの（ネットカフェ、
   コインランドリー、エステなど）が混じる。名前で除外しているが23区側では取り切れていない可能性があり、
   カフェの LQ 0.50 は低めに出ているかもしれない
3. **閉店済み**: Overture は数か月遅れのことがある。confidence 0.5 未満が亀戸で約1割
4. **1km 圏の形**: 西端が錦糸町駅の東側にかかる。錦糸町の店も一部入っている（重複して数える方針どおり）

## 精度の確認

- 店名ルール／Claude 判定と Overture の料理系細分類の両方があった168件で、一致は 88%。
  不一致21件を目で見ると、多くは Overture 側の誤り（亀戸やきそば→ramen、サーティワン→milk_bar など）
- Claude の店名判定は、確信度「高」「中」のものだけを採用し（ルールで決まらなかった53件に適用）、「低」7件は判定不能のまま残している（ほかに「不明」109件、「対象外」8件）。
  判定の根拠は `data/kameido/genre_claude.csv` の reason 列

## OpenStreetMap との照合（2026-10-02 追加）

ローカルで `fetch_osm.py` を実行して取った OSM の飲食店（亀戸駅 1.1km 圏、201件）を使った。

- **判定不能の店はほとんど埋まらなかった**: OSM でジャンルが付いたのは判定不能116件のうち5件
  （うち1件は Claude 判定と同じ店なので、判定不能は 116→112）。OSM に載っているのは
  チェーンや知られた店が中心で、もともとルールで判定できていた店と重なる
- **精度の確認には使えた**: ルールまたは Overture で判定済みの47件のうち、OSM のタグと一致したのは
  42件（89%）。Overture 細分類との照合（88%）とは独立した確認になる。不一致5件
  （`data/kameido/osm_disagreements.txt`）は、なか卯（OSM はうどん）、江戸そば（OSM はラーメン）、
  ロイヤルホスト（OSM はイタリアン）など OSM 側の付け方によるものや、焼肉と韓国料理の境界にあたるもの
- **Overture の取りこぼしが見えた**: 1km 圏内で名前付きの OSM 飲食店112件のうち、Overture の店と
  対応が取れたのは73件（80m 以内・店名一致）。残り39件を調べると、
  - 同名の店が Overture の 300m 以内にあるもの 2件（位置ずれ、または別店舗）
  - 表記が違うだけで Overture にもあるもの 約5件（Sedan／セダン、サブウェイ／SUBWAY、Domino's／ドミノ・ピザ、
    Grande Babbo／ピッツェリアグランデバッボ、Café Italiano La Stella／カフェイタリアーノ ラ・ステラ）。
    今の照合はカタカナと英字の表記違いを同じ店と見なせない
  - **Overture に無いと思われるもの 約32件**。ラーメン店が6件（さん式、らぁ麺たけし、麺 ふじさき、
    亀戸ジンジャーヌードル、DURAMENTEI、そじ坊）、居酒屋・スナック系が10件以上（笑笑、浜焼太郎 など）
  - OSM にある店の 3割弱を Overture が持っていない計算になる。OSM 側にも閉店済みの店が残っている
    可能性はあるので上限の目安。ラーメン・居酒屋が多く漏れているので、これらの件数は今の表より多いはず。
    JFF（食品営業許可）での補完が要る

## JFF（食品営業許可・届出）との名寄せ（2026-10-02 追加）

ローカルで `fetch_openpoi.py` を実行して取った OpenPOI の 1km 圏 1,998 件のうち、JFF 由来は 313 件
（江東区の営業許可一覧 163、厚生労働省の食品衛生申請等システム 200。重なりあり）。

- **名寄せの結果**（`data/kameido/jff_merge.csv`）: Overture と一致 78 / Overture に無い飲食店として追加 94 /
  飲食店以外（保育園・学校・ホテル・コンビニ・ドラッグストア・期間限定の催事など）75 / 飲食店か不確か 66
- 同じ店の判定: 距離と店名（地名・建物名・「居酒屋」「バー」などの業態語を除いて比べる）。JFF の座標は正確で、
  一致した組の距離の中央値は 9m。カナ読みをローマ字に直して英字の店名とも比べる（ロクノタラズ＝Roku no TaRazu、
  松屋＝Matsuya）。店名が完全一致なら 700m まで同じ店とみなす（琉花は Overture 側の位置が 646m ずれていた）
- 追加94件と、不確か66件のうち飲食店と判断できた6件（舎鈴、そじ坊など）を店として加えた。追加分のうち3件は
  Overture の店と同じ店（初代 吉田＝初代亀戸ホルモン吉田 など）だったので除いた → **JFF から 95 件追加**
- 追加分のジャンル: 店名ルール 49、Claude の店名判定 20、判定不能 26。バー・スナック・カフェが多い
- **JFF は全件ではない**: 亀戸 1km 圏の飲食店は Overture だけで約900件あるのに、JFF は飲食店営業として
  載っているものでも約250件しかない。厚生労働省のシステムは電子申請された許可だけが載るようで、
  墨田区は区の一覧が OpenPOI に入っていない。OSM にあって Overture に無かった約35件のうち、JFF で拾えたのは2件だけ
- したがって **Overture＋JFF でもまだ1〜2割の店が漏れている可能性がある**（OSM との照合からの目安）。
  漏れている店にはラーメン店（さん式、らぁ麺たけし、亀戸ジンジャーヌードル など）や居酒屋（笑笑、浜焼太郎 など）が多い
