# 亀戸駅 1km 圏の飲食ジャンル（試作・第1版）

2026-10-02 作成。**Overture のみ**（JFF＝食品営業許可データでの補完と名寄せはまだ）。
数字の元は `data/kameido/genre_table.csv`、店ごとの判定は `data/kameido/genre.csv`。

## 対象と判定率

- 抽出 937 件 → 飲食店でないもの 27 件を除外（ネットカフェ、コインランドリー、地名だけのレコード、
  フードコート全体、住所が丸の内の誤位置レコードなど）→ 910 件 → 同一店の重複9組をまとめて **対象 901 件**
- 判定の内訳（重複をまとめる前の910件）: 店名ルール 483 / Overture 細分類 258 / Claude の店名判定 53 / **判定不能 116**
- **最終判定率 87.1%**。比較用のルールのみの判定率は 81.8%（23区は 73.4%）

## 特化係数（LQ）の読み方

- 比較対象は **東京23区をおおむね覆う bbox 内の Overture 飲食 POI**（138,909 件、飲食店以外を除き重複をまとめて 135,837 件）。23区の境界では切っていないので、
  隣接する市の一部も入っている
- 駅側も23区側も「店名ルール＋Overture」だけで判定した結果で比べている（Claude 判定は23区側に無いため）
- 構成比の分母は判定できた店だけ
- 重複レコードは両側とも同じ条件（50m 以内・店名の中核が一致または包含・同じジャンル）でまとめてから数えている
- **件数が10件未満のジャンルの LQ は参考程度**。1〜2店の増減や重複レコードで大きく動く

## 読み取れそうなこと（暫定）

件数が多く、分類の揺れにも強いものだけ挙げる。

- **多い（LQ 1.3以上・20件以上）**: 焼肉・ホルモン 1.45、ラーメン 1.48、焼き鳥・やきとん 1.39。
  肉・麺・串の店が厚い
- **少ない（LQ 0.8未満）**: カフェ・喫茶 0.50（57件）、すし 0.72（26件）、パン 0.67（17件）、
  そば・うどん 0.61（12件）、フレンチ・ビストロ 0.61（11件）。後ろの3つは件数が少なめなので幅を持って読む
- 酒場系（居酒屋＋バー＋スナック・パブ）をまとめると LQ **1.04** でほぼ平均並み。居酒屋 1.59 とバー 0.79 の差は、
  店名に「居酒屋」「酒場」と書く店が多いかどうかと、Overture が izakaya を bar と sake_bar のどちらに入れるかの
  違いでほぼ説明できる。酒場系の中の内訳は今のところ比べられない

## 誤差の主な原因

1. **重複レコード**: 同じ店が複数レコードになっている。保守的な条件（`scripts/dedupe.py`）で9組はまとめたが、
   表記違い（Lali Guras／ラリグラス）、距離が離れたもの（亀戸升本）、ジャンルが割れたもの（ざうお）は残っている。
   23区側の重複除去は 1.3%。JFF との名寄せのときに条件を見直す
2. **カフェの比較対象**: Overture の cafe / coffee_shop には飲食店でないもの（ネットカフェ、
   コインランドリー、エステなど）が混じる。名前で除外しているが23区側では取り切れていない可能性があり、
   カフェの LQ 0.50 は低めに出ているかもしれない
3. **閉店済み**: Overture は数か月遅れのことがある。confidence 0.5 未満が亀戸で約1割
4. **1km 圏の形**: 西端が錦糸町駅の東側にかかる。錦糸町の店も一部入っている（重複して数える方針どおり）

## 精度の確認

- 店名ルール／Claude 判定と Overture の料理系細分類の両方があった168件で、一致は 88%。
  不一致21件を目で見ると、多くは Overture 側の誤り（亀戸やきそば→ramen、サーティワン→milk_bar など）
- Claude の店名判定は、確信度「高」「中」のものだけを採用し（ルールで決まらなかった53件に適用）、「低」7件は判定不能のまま残している（ほかに「不明」109件、「対象外」8件）。
  判定の根拠は `data/kameido/genre_claude.csv` の reason 列
