# 次に取り込むデータ（ユーザーがダウンロードする分）

この作業環境からは e-Stat・国土数値情報・国土交通省のサイトに接続できないため、ファイルをダウンロードして
リポジトリに入れてもらう。入れる場所はそれぞれ書いた通り。届いたら取り込みはこちらで行う。

## 1. 人口・年齢層（駅カードの「人口」）

国勢調査 2020 の地域メッシュ統計（250m メッシュ、なければ 500m）。

1. e-Stat（https://www.e-stat.go.jp/）→「地図」（統計GIS）→「統計データダウンロード」
2. 「国勢調査」→「2020年」→「5次メッシュ（250mメッシュ）」を開く
3. **「人口及び世帯（JGD2011）」** と **「５歳階級別人口（JGD2011）」** の2つを選ぶ（JGD2000 版は古い測地系。どちらでもメッシュは同じだが、新しい方にそろえる）
4. 1次メッシュ **5339** を選んでダウンロード（23区は全部 5339 に入る。北緯35°20′〜36°00′、東経139°〜140°）
5. zip を展開して `.txt`（CSV）を `data/mesh/` に入れて push

取り込み: `python scripts/mesh_stats.py data/mesh/*.txt --inspect` で項目名を見てから、
`--cols "人口=人口（総数）,..."` で駅の 300/500/1000m 圏の人口を出す（`scripts/mesh_stats.py`）。

## 2. 働く人の数（昼の人口の代わり）　※取り込み済み（tblT001147H5339）

経済センサス‐活動調査 2021 の地域メッシュ統計（500m または 250m、「従業者数」）。
手順は 1 と同じで、「経済センサス‐活動調査」→「2021年」を選ぶ。`data/mesh/` に入れる。

## 3. 地価（見送り）

ユーザーの判断で見送り（2026-10-05）。調べた内容は `docs/parking_research.md`。

## 4. 住所からの検索（地点分析）　※取り込み済み（data/isj/13_2025.csv、街区レベル）

国土交通省「位置参照情報」（大字・町丁目レベル、東京都）。住所（○○区○○町△丁目）から緯度経度を引くのに使う。
https://nlftp.mlit.go.jp/isj/ → 最新年 →「大字・町丁目レベル」→ 東京都 → zip の中の CSV を `data/isj/` に入れる。
利用条件も確認する。番地まで細かく引くには「街区レベル」（ファイルが大きい）が必要。
