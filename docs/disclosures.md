## 3. 数字の作り方・限界

- 店の数は地図サービスに登録された件数で、実際の店数と一致しない。23区全体で経済センサスの約1.9倍、
  都心ほど多め（千代田 2.6倍）、郊外ほど少なめ（足立 1.2倍）。「補正後」の店数はこの差を区×業種ごとに調整した値
- ジャンルは店名・分類から自動で判定している（店名の規則、地図サービスの分類、AI〔Claude〕による店名からの判定）。
  中分類まで判定できた店は約83%、大分類まで判定できた店は約98%（別ページの留意点にも書く）。誤りが含まれる。AI の判定は確信度「高」「中」だけを使い、「低」は大分類にだけ使う
- 中分類が分からない店がある（特に和食・バー）。構成比・平均比は中分類が分かる店だけを分母にしている
- 平均比（中身は特化係数 LQ）＝その駅周辺のジャンルの割合 ÷ 対象地域全体（23区なら23区全体）の割合。
  経済センサスで地図サービスの偏りを補正した値なので、構成比どうしの比とは少し違う（下の「平均比の補正」）。画面の「?」に定義と例を出す
- 店が少ないジャンルは、数店の違いで平均比が大きく動く
- 「少ないジャンル」（各駅情報）と「少ない駅」（ジャンル別）には、23区平均の割合なら3店以上あるはずのジャンルだけを出す。「多い」は実際に3店以上あるものだけ
- 円（250/500/1000m）が重なる駅どうしでは、同じ店をそれぞれの駅で数えている
- 円の中に飲食店が1軒もない駅もある（250m圏の辰巳・昭和島・舎人公園、500m圏の昭和島）。店数0として表示する
- 円が23区の外（隣の市や海・運河など）にかかる駅は、外側の店がデータに含まれないため、店の数が少なめに出ることがある。各駅情報にその旨を出す
  （判定は区の境界の外周で行う。境界データの川・堀の穴は埋めてから判定し、内陸の駅を端と誤らないようにしている）
- 乗降客数: 乗換駅は事業者ごとの値を合計（同じ駅名で500m以内の駅もまとめた）。同じ事業者の重複は除いた。乗降客数が公表されていない駅（とうきょうスカイツリー、上野動物園のモノレール2駅）は、出店ナビ全体で扱っていない（地図にも出ない）
- 乗降客1万人あたり店数は、補正後の店数を乗降客数で割った値（画面の「飲食店」は補正前の件数なので、それを割った値とは一致しない。画面の「?」に記載）。円の重なりのため小さい駅ほど大きく出る
- 所得・客単価・売上・賃料・地価は含まない
- 「少ないジャンル」は出店の好機を意味するとは限らない（需要そのものが少ない場合がある）

### 平均比の補正（経済センサスによる）

**なぜ補正するか**: 地図サービスの店は、業種によって登録されやすさが違う。区ごと・業種ごとに経済センサス（2021年）の事業所数と比べると、
渋谷区では居酒屋など（酒場・ビヤホール）が約1.1倍なのに対し、バーは約3.0倍、カフェ（喫茶店）は約3.8倍登録されている
（地図サービスの件数は、ジャンルが分からない店の分を割り振った推定値）。補正しないと、バーやカフェが実際より多く見える。

**補正のしかた**:
1. 区ごと・センサスの業種ごとに「センサスの事業所数 ÷ 地図サービスの件数」を計算し、店1件の重みにする
   （例: 渋谷区のバーは 453 ÷ 1,346 ≒ 0.34、居酒屋は 793 ÷ 841 ≒ 0.94）
2. 駅のまわりの割合も23区全体の割合も、重みを掛けた件数で計算する
3. その比を平均比として画面に出す

**例（渋谷駅 1000m 圏）**: 居酒屋 0.96倍 → 補正後 1.14倍、バー 1.45倍 → 1.10倍、カフェ・喫茶 1.30倍 → 1.27倍、すし 0.71倍 → 0.68倍。

**限界**:
- 補正は区の単位。同じ区の中で駅ごとに登録のされ方が違う分は残る
- センサスの業種区分は粗い（「専門料理店」にラーメン・焼肉・イタリアン・中華などがまとまる）ので、同じ区分の中分類は同じ重みになる
- パン・スイーツ・惣菜はセンサスでは小売業などに入り比べる相手がないため、ジャンル不明の店と同じく、その区の飲食店全体の重みを使う
- センサスは2021年、店のデータは2026年8月時点で、時点が違う
- 計算は `scripts/census.py`（重み）と `scripts/station_table.py`（LQ_w）。重みの一覧は `data/census/weights_tokyo23.csv`

## 4. 地図

- 地図は国土数値情報の線路・区の境界だけで描いている（外部の地図タイルは使わない）
- 路線の区分（JR・私鉄・地下鉄）は路線名から付けた。私鉄には都電・モノレール・ゆりかもめ・りんかい線・日暮里舎人ライナーなどを含む
- 線路を共用する区間は、元データで一方の路線名しか付いていないことがあり、線を指したときの路線名がもう一方になることがある
- 車両基地の線、廃線跡、計画中の線は描いていない
- 23区の外の線路は、区の境界の少し外で切っている

## 5. 地点分析（任意の地点から 50/100/250m）

- 地点は駅名・住所・座標（緯度・経度）のどれかで指定する
- 「近隣店の一覧」の見出しの右に「Googleマップでこの地点を開く」リンクを置く（Google の公開しているリンクの形式。API は使わず、Google のデータをこのサイトに取り込まない。
  営業時間・価格帯・評価はユーザーが Google マップで見る。Places API で取り込んで表示するのは、Google 以外の地図との併用禁止・保存の制限・費用のため見送り）
- 「AIで調べる用にコピー」ボタン: 表示中の近隣店（近い順に最大50店。ジャンルで絞り込んでいればその店だけ）の店名・ジャンル・距離・緯度経度と、
  営業時間・価格帯・Google の評価などを調べてほしいという依頼文を一緒にコピーする。ユーザーが自分の AI チャットに貼って調べる。
  AI の調べた結果には誤りや古い情報が含まれることがあるので、必ず確かめるよう画面に書く。自動でコピーできないブラウザでは、選択した状態の文章を出す
- 範囲内の店は「ジャンル別の店数」（大分類ごとに中分類の店数を多い順に並べる。中分類が分からない店は「中分類不明」）と、
  「近隣店の一覧（指定地点から近い順）」で見せる。範囲が狭く店が少ないので、平均比は出さない
- 店の位置は地図サービスの登録位置で、数十m ずれることがある。50m の範囲は特にずれの影響を受けやすい
- 店名の一覧には閉店済みの店が残っている場合がある
- 住所は国土交通省「位置参照情報（街区レベル、2025年）」で「区・町・丁目・番」まで引く（号は使わない）。番が見つからないときは丁目の中心、丁目もなければ町の中心で分析する。どこまで引けたかを画面に出す
- 座標は Google マップなどで調べた値を貼り付ける。23区の外の地点は、外側の店がデータにないため正しく出ない

## 6. 人口・働く人（各駅情報）

- 2020年国勢調査の 250m メッシュ統計を、駅から半径 R の円と重なる面積の割合で配分して足した推計値（メッシュ内で人口が均等とみなす）
- 秘匿されたメッシュ（少人数）は 0 として扱った
- 住んでいる人の数で、昼間にいる人（通勤・買い物客）は含まない
- 1人世帯の割合は、一般世帯のうち1人世帯の割合（分母は一般世帯。寮・病院などの施設等の世帯は含まない）
- 住む人が500人未満の円（東京駅・大手町・羽田空港などの250m圏など）は、割合や「働く人 ÷ 住む人」が数人の違いで大きく動くので、
  割合（1人世帯・外国人・年齢構成）と「働く人 ÷ 住む人」は出さない（「—」と注記）。駅周辺の特徴の文章でも住民の構成には触れない
- 年齢構成は 0〜14歳・15〜19歳・20〜34歳・35〜49歳・50〜64歳・65歳以上の6区分。「年齢不詳」は、国勢調査で年齢が分からない人
- 働く人の数は 2021年経済センサスの 500m メッシュ（従業者数）を同じ方法で配分した推計値。500m メッシュは円より粗いので、250m 圏では特に誤差が大きい
- 従業者数は事業所で働く人の数で、通学者・買い物客は含まない（画面の「?」に記載）
- 「働く人 ÷ 住む人」は昼間に人が集まる度合いの目安で、国勢調査の昼間人口とは定義が違う（画面の「?」に記載）
- 「オフィス・商業系」は経済センサスの産業大分類 Ｇ情報通信・Ｉ卸売小売・Ｊ金融保険・Ｋ不動産・Ｌ専門サービス・Ｒその他サービス（警備・ビル管理・派遣など）の合計。卸売（商社・問屋）と小売（店）は統計上分けられない（画面の「?」に記載）
- 比較の基準の「23区平均」は、23区全体のメッシュを足した値

## 7. 駅周辺の特徴（各駅情報の文章）

- 店の構成と人口・働く人の数字から、決まった規則で自動的に作った文章（人が取材して書いたものではない）。
  **画面で選んだ半径に関わらず、駅から250mの範囲の数字で作る**（ユーザー決定 2026-10-05。駅のすぐまわりの性格を表すため）。文章は4つの部分からなる
  1. どんな街か: 「働く人 ÷ 住む人」（3倍以上でオフィス街、1.3倍以上でオフィスと住宅が混じる、0.5倍以下で住宅地）と人口密度、
     飲食店の密度（国の統計で補正した店数。23区平均の3倍以上で「非常に多い」、1.5倍以上で「多い」、0.5倍未満で「少ない」）
  2. 昼と夜の需要: 昼は「働く人 ÷ 住む人」から。夜は居酒屋・バー（焼き鳥・スナック・串かつを含む）の数の密度
     （まとまりの平均比 × 飲食店の密度。2.5倍以上で「多い」、1.2倍以上で「一定数」、0.6倍未満で「少ない」）から
  3. 住んでいる人: 23区平均より目立つ層（20〜34歳の単身者・子どものいる世帯・10代後半・65歳以上・外国人）があるときだけ
  4. 飲食店の構成: 食事処・日常使いの店のまとまりが多いとき（平均比 1.2倍以上）と、平均比 1.3倍以上・3店以上のジャンル（上位3つ）。
     **少ないジャンルは文章に書かない**（ユーザー決定 2026-10-05。画面の「少ないジャンル」の表で見られる）
- 乗降客数の多さは文章に書かない（すぐ上に乗降客数と順位が出ているため）
- 飲食店のまとまり（夜の飲み・日常使い・食事処）の平均比は、画面の平均比と同じくセンサス補正後の値で計算する
  （23区平均なら3店未満のまとまりは判定しない。「少ないジャンル」と同じ基準）
- 住む人が500人未満の円は「住む人がほとんどいない」と書き、住民の構成には触れない
- **空港・展示場・市場・物流地区など、駅のまわりの人口や店のデータでは性格を表せない駅**（羽田空港の各駅・整備場・新整備場・
  東京ビッグサイト・国際展示場・市場前・流通センター・新木場・昭和島・葛西臨海公園・東京国際クルーズターミナル）は、
  データから文章を作らず、一般的な情報をもとに手で書いた説明を出す（`data/station_notes.csv`。見出しは「駅周辺の特徴（一般的な情報による）」）。
  施設の変化（新しい施設の開業・閉鎖など）があれば書き直す

## 8. 乗降客数（乗降客数タブ）

- 1日平均乗降客数（2024年、S12-25）の多い順に並べている。乗換駅の合算の仕方は 3. と同じ
- 対象は 488 駅（乗降客数が公表されていない駅は除く。3. を参照）
- 同じ名前の別の駅（浅草・早稲田）は、駅名に路線名を添えて区別している（例: 浅草（つくばエクスプレス））
- 路線を選ぶと、その路線を地図で強調する。路線の区分と路線名の限界は 4. と同じ
