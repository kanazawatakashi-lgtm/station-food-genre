# 駅周辺の駐車料金を地価の代わりに使えるか（2026-10-04 調べ）

**2026-10-05: 地価はユーザーの判断で見送り。** 以下は調べた記録として残す。

ユーザーの案: 駅周辺の時間貸し駐車場の料金（30分または1時間あたり）を、地価の簡単な代替指標にする。

## 結論

- **無料で商用に使える駐車料金のデータは見つからなかった。** 料金をまとめたデータは民間の有料サービスだけ。
- 駐車場運営会社（タイムズ、三井のリパークなど）や検索サイトのページから料金を集める方法は、各社の利用規約で
  データの収集・転用が制限されていることが多く、有料サービスの元データにはできない（規約を個別に確認していない）。
- 地価そのものは国の公開データ（地価公示）があるので、**代替指標を作るより地価公示を直接使う方がよい**。

## 駐車料金のデータ（いずれも有料・法人向け）

| サービス | 内容 | 条件 |
|---|---|---|
| PPPark! 駐車場検索 API | 全国の時間貸し駐車場の検索・料金 | 月額6万円からの従量制（検索結果より） |
| NAVITIME 駐車場検索 API | 約9.9万件、満空情報あり | 法人向け、要問い合わせ |
| P-Collection API（パーキングサイエンス） | 約15万件、料金計算 | 要問い合わせ |
| Parkopedia | 10万件以上、料金・営業時間 | 要問い合わせ |
| ナビット 全国駐車場データベース | 約10万件、CSV/API | 有料 |

駐車料金は、30分単位の料金表示が多い（都心では「20分○円」「15分○円」もある）。最大料金や時間帯別料金があり、
「30分あたり」にそろえるには料金体系の解釈が要る。仮に有料データを使う場合も、駅ごとに「昼間の30分あたり料金の中央値」
のような指標を決める必要がある。

## 地価のデータ（無料・公的）

| データ | 内容 | 条件（要確認） |
|---|---|---|
| 国土数値情報 L01（地価公示）、L02（都道府県地価調査） | 標準地ごとの1m²あたり価格（毎年）、用途（商業地・住宅地など） | 平成31年以降の版はオープンデータ（検索結果では CC BY 4.0／公共データ利用規約）。出典「国土数値情報（地価公示データ）」（国土交通省）とページの URL を書く。使う版の条件をデータページで確認する |
| 不動産情報ライブラリ API（国土交通省） | 地価公示・地価調査、不動産取引価格など | API 利用申請（審査あり、5営業日程度）。サービスで使う場合は所定のクレジット表示が必要。一部、商用で使えないデータがある |

駅ごとの地価の出し方（案）: 駅から 500m 以内の**商業地**の地価公示地点の価格の中央値（地点がなければ 1km まで広げる）。
地価公示は全国にあるので、他の地域に広げるときもそのまま使える。

## 次にやること

- 国土数値情報 L01（地価公示、最新年、東京都）をダウンロードしてもらう（利用条件もデータページで確認してもらう）
- 確認できたら駅カードに「駅周辺の商業地の地価（中央値）」を追加する
